# SecureAct AI Platform (v2.0)
## منصة الذكاء الاصطناعي لكشف محاولات حقن التعليمات (Prompt Injection Detection Platform)

منصة أمنية متكاملة للكشف الاستباقي عن محاولات حقن التعليمات والأوامر الخبيثة (Prompt Injection) داخل نصوص وصفحات ويب HTML، باستخدام نموذج `SecureAct_AI_v2` المدرب مسبقاً والمبني على مصنف `LinearSVC` ومصفوفات TF-IDF.

---

## 1. المعمارية الفنية (Technical Architecture)

- **الواجهة الأمامية (Frontend):** React 18 + TypeScript + Vite.
  - واجهة داكنة تقنية احترافية (Glassmorphic Dark Theme).
  - لغة عربية افتراضية مع دعم كامل للاتجاه RTL، وتبديل فوري للإنجليزية LTR.
- **الخادم وواجهة البرمجة (Backend & API):** Python 3.12+ / FastAPI / Uvicorn / Pydantic v2.
  - تحميل النموذج كخدمة أحادية (Singleton).
  - تحقق إلزامي من بصمة التشفير SHA-256 للنموذج قبل بدء التشغيل.
- **نموذج التعلم الآلي (Machine Learning):**
  - **النموذج:** `SecureAct_AI_v2`
  - **المرشح المختار:** `html_word_char_linear_svc`
  - **المصنف:** `LinearSVC` مع دالة القرار `decision_function()`
  - **الخصائص:** TF-IDF للكلمات (n-grams من 1 إلى 2) وللأحرف (n-grams من 3 إلى 5)
  - **عتبة القرار:** `-0.23754153513923493`
  - **قاعدة القرار:** `score >= threshold` تعني مؤشر حقن محتمل (`potential_injection`)، وما دون ذلك سليم (`benign`).
  - **بصمة SHA-256 المتوقعة والمتحقق منها:**
    `8569185d875a1bd76768e1a576c1cfcfd8ff6d74529cd5e646f67d610f2ece5c`

## 3. ضوابط الأمان وحدود الإدخال (Security & Limits)

| الضابط | الحد المعتمد | السلوك ورمز الاستجابة |
|---|---|---|
| **حجم الملف المرفوع** | **100 KiB** (102,400 بايت) | رفض فوري برمز **HTTP 413** |
| **حجم طلب HTTP كاملاً** | **1 MiB** (1,048,576 بايت) | فحص عبر Middleware ورفض برمز **HTTP 413** |
| **طول النص بعد فك الترميز** | **100,000 حرف Unicode** | تحقق مستقل بالخادم ورفض برمز **HTTP 400** |
| **أنواع الملفات المسموحة** | `.html` و `.txt` فقط | رفض الأنواع الأخرى برمز **HTTP 400** |
| **تحديد معدل الطلبات** | **30 طلباً في الدقيقة** لكل IP | حظر مؤقت برمز **HTTP 429** مع `Retry-After` |

## 4. خطوات التشغيل المحلي (Local Quickstart)

### المتطلبات الأساسية:
- Python 3.12 أو أحدث
- Node.js 18+ و npm

### أ. تفعيل البيئة الوهمية وتشغيل الخادم:
```bash
# الانتقال إلى مجلد المشروع
cd SecureAct_AI_Platform

# تشغيل خادم FastAPI (أمر متوافق عبر الأنظمة):
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```
سيعمل الخادم على: `http://127.0.0.1:8000`  
ويمكن استعراض توثيق Swagger التفاعلي عبر: `http://127.0.0.1:8000/docs`

### ب. تشغيل الواجهة الأمامية:
```bash
cd frontend
npm install
npm run dev
```
ستعمل الواجهة على: `http://127.0.0.1:5173`

## 6. نقاط النهاية الأساسية للـ API (Endpoints)

- `GET /health` — فحص جاهزية النظام والتحقق من تحميل النموذج ومطابقة SHA-256.
- `GET /api/model-info` — استرجاع البيانات الوصفية وهندسة الخصائص وتفاصيل بيئة التدريب.
- `GET /api/metrics` — استرجاع مقاييس الاختبار المعتمدة وفواصل الثقة ومقارنة v1 و v2.
- `POST /api/predict` — فحص نص أو شفرة HTML واستخراج درجة القرار وهامش العتبة.
- `POST /api/predict/file` — فحص ملف مرفوع (.html أو .txt حتى 100 KiB).
- `POST /api/scan-url` — جلب وفحص صفحة ويب فردية بأمان مع حماية SSRF متقدمة.
- `POST /api/scan-batch` — فحص جماعي لما يصل إلى 10 روابط بالتوازي مع عزل الأخطاء.
- `GET /api/demo/cases` — استرجاع الحالات التجريبية النموذجية المعتمدة.
- `POST /api/demo/batch` — تنفيذ الاستدلال المباشر على كافة الحالات التجريبية.

## 7. الجاهزية والنشر السحابي (Deployment Architecture)

- مهيأ للنشر على منصة **Vercel** بنظام Monorepo يجمع واجهة React الثابتة مع دالة Serverless بايثون (`/api/index.py`).
- حماية استباقية من ثغرات SSRF تغطي أكثر من 20 شبكة محجوبة بما فيها loopback وعناوين السحابة الخاصة (AWS/GCP Metadata).
- حدود صارمة لأحجام الطلبات (1 MiB للطلب، 100 KiB للملف، 100k حرف للنص).

## 8. إفصاح علمي وأكاديمي (Scientific Notice)
هذا النموذج مصمم كأداة بحثية متقدمة للكشف عن مؤشرات حقن التعليمات (Prompt Injection). لا يقدم النموذج ضماناً مطلقاً للسلامة بنسبة 100%، حيث يسجل معدل إنذار كاذب قدره 6.03% على عينة الاختبار المحلية. يجب استخدام المنصة كطبقة مساندة ضمن استراتيجية الدفاع في العمق (Defense-in-Depth).
